# 08 车载电源分配板方案

本文档记录 OpenRD 车载电源分配板的第一版设计约束、原理图连接规划、PCB 布局规划和上电测试流程。

目标不是第一版就自研 buck-boost 电源，而是先做一块可靠的电源分配/模块载板，把 3S 12V 电池、电机驱动板、RK3588、ESP32 供电路径理清并固定下来。

## 已知条件

### 电池

当前配套电池为 3S 12V 锂电池组：

```text
标称电压：11.1V
满电电压：12.6V
放电截止：8.1V
额定容量：4400mAh
额定电流：约 6A
电芯结构：三串两并
放电接口：航模 T 插 / Deans T plug
充电接口：DC 圆口 5.5 x 2.1
```

第一版电源板只处理电池放电路径，不接入电池充电口。电池充电仍使用原厂充电器直接接电池 `DC5521` 充电口。

### RK3588

主控板为正点原子 `TL-ATK-RK3588B / ATK-DLRK3588B`：

```text
电源输入：DC 12V
电源口：DC 圆口 5.5 x 2.5
设计预留：12V / 5A
```

由于 3S 电池电压会在 `12.6V -> 8.1V` 之间变化，RK3588 不建议直接接电池裸压。第一版采用独立 12V buck-boost 模块给 RK3588 稳压供电。

### ESP32

当前电机驱动板可以给 ESP32 供电，并且现有实车链路已验证可用。因此第一版默认：

```text
12V 电池 -> 电机驱动板 -> ESP32
```

电源分配板只预留可选 `5V/GND` 输出，不把 ESP32 供电作为第一版必需功能。

## 设计目标

- 使用嘉立创 EDA 网页版绘制；
- PCB 控制在 `100mm x 100mm` 以内，优先使用免费打样范围；
- 2 层板，默认 1oz 铜厚；
- 4 个 M3 安装孔；
- 电池输入使用航模 T 插；
- 电机驱动输出使用航模 T 插；
- RK3588 输出为稳压 12V，经线缆接 `DC5525` 公头；
- DC-DC 模块选择 50 元以内的现成 buck-boost 模块；
- 电机大电流路径尽量短、宽、低阻；
- RK3588 支路与电机支路分开走线、分开保护；
- 全系统共地，但电机大电流回路和小信号/采样回路布局分区。

## DC-DC 模块选择

第一版建议使用常见 `LTC3780 自动升降压恒压恒流模块 / 10A 款`。

选择理由：

- 典型输入范围覆盖 3S 电池；
- 可输出稳定 12V；
- 价格通常可控制在 50 元以内；
- 常见模块资料标称最大电流较高，给 RK3588 预留 `12V/5A` 比普通 5A 小模块更稳；
- 模块化方案风险低，不需要第一版调试开关电源环路。

注意：

- 不同店铺 LTC3780 模块尺寸、接线端子、孔距可能不同；
- 常见尺寸约 `78mm x 47mm`，但不能在 PCB 中写死为唯一版本；
- PCB 第一版采用“模块安装区 + 大电流端子/焊盘连接”的方式；
- 最终进入嘉立创 EDA 画板前，需要用实际购买链接或实物测量确认模块外形、孔径、孔距和端子位置。

公开模块资料里常见 LTC3780 成品模块参数为：输入 `5V-32V`、输出 `1V-30V`、最大 `10A`、连续约 `7A / 80W`、模块尺寸约 `78mm x 46mm x 15mm`。这能覆盖 RK3588 的稳压需求，但不代表可以长期无散热满载运行；第一版必须按实际温升验证。

### v0.1 默认模块机械尺寸

为便于先开始绘板，v0.1 暂时固定一个通用 LTC3780 模块尺寸。这个尺寸用于第一版 EDA 草图，不等于最终采购约束。

```text
U1 LTC3780 module body: 78mm x 46mm
U1 height keepout: 15mm
U1 PCB keepout/silkscreen box: 82mm x 52mm
Mounting hole count: 4
Mounting hole diameter: 3.2mm
Mounting hole spacing: 70mm x 38mm
Hole inset from module body edge: 4mm
```

在 `95mm x 95mm` PCB 上，U1 默认居中在 `(48, 43)`，对应：

```text
U1 body bbox: x=9..87, y=20..66
U1 keepout bbox: x=7..89, y=17..69
U1 hole centers:
  U1H1: (13, 24)
  U1H2: (83, 24)
  U1H3: (13, 62)
  U1H4: (83, 62)
```

如果实际买到的模块孔距不同，优先移动 U1 固定孔，不改电气网络。模块输入/输出仍用短粗线连接 `J3/J4`，避免端子位置不同导致整板重画。

### 电流预算提醒

12V 电池文档给出的额定电流约 `6A`。这意味着整车连续功率预算大约是：

```text
11.1V * 6A = 66.6W
```

而 RK3588 预留 `12V / 5A` 是 `60W` 级别，再叠加电机启动电流后会超过电池额定连续输出。因此第一版设计按以下原则处理：

- `12V / 5A` 是 RK3588 供电支路的设计预留，不等于整车长期工况；
- RK3588、摄像头、视频编码、无线网络实际电流需要后续用表实测；
- 电机启动、大转向、堵转时会造成电池电压下陷，必须观察 RK3588 是否重启；
- 若实测同时高负载不稳定，优先降速、限制电机电流，或升级电池/供电方案；
- 第一版 PCB 不依赖细铜线承载主回路电流，主电流区必须大面积铺铜并保留补锡/铜线加强能力。

## 总体电源树

```text
3S 12V Battery
  Deans T plug
    |
    v
J1 BATT_IN
    |
F1 总保险
    |
SW1 总开关
    |
BAT_SW_12V 母线
    |-------------------- J2 MOTOR_OUT -> 电机驱动板 -> ESP32
    |
    |---- F2 RK 支路保险
    |---- J3 DCDC_IN -> LTC3780 IN
              LTC3780 OUT -> J4 DCDC_OUT
    |---- J5 RK_OUT -> DC5525 公头线 -> RK3588
    |
    |---- R1/R2 电池分压 -> J6 ADC/Test header
    |
    |---- LED1 电源指示
```

## 原理图规划

### 电源输入

```text
J1: BATT_IN
  pin 1: BATT+
  pin 2: GND
```

实现建议：

- 第一版优先使用大焊盘 + T 插线束，而不是强依赖某个板载 T 插封装；
- 焊盘附近预留 2 个扎带孔，给输入线做应力释放；
- 丝印明确标注 `BATT+`、`GND`、`3S BATTERY IN`；
- 输入附近放大电解电容和 TVS 预留位。

推荐器件：

```text
C1: 470uF-1000uF / 25V 电解电容
C2: 0.1uF / 50V 陶瓷电容
D1: TVS 预留位，SMBJ18A 或同级别，第一版可选焊
TP1: BATT+
TP2: GND
```

### 保护与开关

```text
F1: 总保险
SW1: 总开关
```

建议：

- F1 使用汽车片式保险丝座或大电流保险丝座；
- 第一版总保险建议从 `10A` 起步，根据实际电机电流再调整；
- SW1 如果板载开关额定电流不足，必须只作为控制信号，不直接硬扛电机电流；
- 简化第一版可以使用额定足够的外置船型开关/线束开关，PCB 上预留 `SW1` 两孔接口。

两种实现选项：

```text
方案 A：板载大电流开关
  优点：集成度高
  风险：要确认开关 DC 电流额定值和发热

方案 B：板载开关接口 + 外置大电流开关
  优点：安全、好买、好换
  风险：线束稍多
```

第一版建议优先方案 B。

### 电机驱动输出

```text
J2: MOTOR_OUT
  pin 1: MOTOR_12V
  pin 2: GND
```

连接：

```text
BAT_SW_12V -> J2 pin 1
GND        -> J2 pin 2
```

实现建议：

- 使用大焊盘 + T 插线束；
- 预留扎带孔；
- 这一路是电机大电流路径，应尽量短、粗、直；
- 顶层和底层都铺铜，过孔阵列并联；
- 可预留开窗焊锡或铜条补强区。

### RK3588 稳压支路

```text
F2: RK branch fuse
J3: DCDC_IN
J4: DCDC_OUT
J5: RK_OUT
```

连接：

```text
BAT_SW_12V -> F2 -> J3 DCDC_IN+
GND        -> J3 DCDC_IN-

J4 DCDC_OUT+ -> J5 RK_12V+
J4 DCDC_OUT- -> J5 GND
```

建议：

- F2 可用 `5A-7.5A` 保险丝，实际按 RK3588 负载调整；
- J3/J4/J5 使用 5.08mm 间距大电流端子或大焊盘；
- J5 输出到 `DC5525` 公头线，接 RK3588 DC 输入；
- 输出旁边预留测试点 `RK_12V` 和 `GND`；
- 输出旁边可预留 `C3 470uF/25V` 和 `C4 0.1uF/50V`。

LTC3780 模块本身通过螺丝柱固定在 PCB 上，模块输入/输出用短线接到 J3/J4。这样即使不同供应商模块孔距略有变化，也可以通过安装孔长圆孔或转接线兼容。

### 可选 5V 预留

第一版不强制上 5V DC-DC，但建议预留：

```text
J7: AUX_5V
  pin 1: 5V
  pin 2: GND
```

用途：

- 后续给 ESP32、灯、传感器或风扇供电；
- 当前可不焊 5V 模块；
- 如果后续启用，必须确认 5V 模块输入范围和电流能力。

### 电池电压采样

预留分压采样给 ESP32 ADC 或外接 ADC。

```text
BATT_SENSE = BATT+ 经 R1/R2 分压
```

建议分压：

```text
R1 = 100k
R2 = 27k
```

满电 12.6V 时：

```text
Vadc = 12.6 * 27 / (100 + 27) = 2.68V
```

适合 3.3V ADC 输入。若实际 ADC 参考、电阻精度或 ESP32 ADC 非线性影响较大，软件中做校准。

接口：

```text
J6: ADC/Test
  pin 1: BATT_SENSE
  pin 2: GND
  pin 3: BATT+ 或 3V3_REF 预留，不默认接
```

保护建议：

- BATT_SENSE 串 `1k-4.7k` 电阻；
- ADC 输入可预留 3.3V 钳位二极管或 TVS，小电流采样第一版可不焊；
- 分压电阻靠近采样接口，远离电机大电流路径。

### LED 指示

```text
LED1: BAT_SW_12V power indicator
Rled: 2.2k-4.7k
```

作用：

- 总开关打开后亮；
- 可快速判断电源板是否有母线电压。

## 建议原理图网络命名

```text
BATT+
BAT_SW_12V
MOTOR_12V
DCDC_IN_12V
RK_12V
BATT_SENSE
GND
```

说明：

- `BATT+` 是保险丝和开关前的电池正极；
- `BAT_SW_12V` 是总开关后的 12V 母线；
- `MOTOR_12V` 与 `BAT_SW_12V` 可同网，也可以通过 0R/保险丝分出；
- `RK_12V` 是 DC-DC 输出后的稳定 12V；
- 所有 GND 共地。

## PCB 布局规划

### 尺寸与安装

```text
PCB 外形：建议 95mm x 95mm，保留制造和安装余量
最大限制：100mm x 100mm
安装孔：4 x M3
安装孔孔径：3.2mm
安装孔到板边：5mm-6mm
板厚：1.6mm
铜厚：第一版 1oz
```

建议安装孔坐标，以 `95mm x 95mm` 为例：

```text
H1: (5, 5)
H2: (90, 5)
H3: (5, 90)
H4: (90, 90)
```

### 功能区布局

建议布局：

```text
┌────────────────────────────────────────────┐
│ J1 BATT_IN          F1/SW1        J2 MOTOR │
│  T plug in       fuse/switch       T out   │
│                                            │
│  high-current 12V/GND copper bus           │
│                                            │
│ ┌────────────────────────────────────────┐ │
│ │ LTC3780 buck-boost module area         │ │
│ │ approx 78mm x 47mm                     │ │
│ └────────────────────────────────────────┘ │
│                                            │
│ J3 IN     J4 OUT       J5 RK_OUT           │
│                                            │
│ ADC/LED/Test points                        │
└────────────────────────────────────────────┘
```

原则：

- T 插输入和电机输出靠近板边；
- 电机大电流路径尽量在板上边缘短距离通过；
- LTC3780 模块放中间或偏下，给散热和螺丝留空间；
- RK 输出靠近模块输出侧；
- ADC、LED、测试点放远离电机大电流路径的一侧；
- 输入线、输出线、RK 电源线都应有清晰丝印方向。

建议把上边 `y=70-90` 作为高电流输入/电机输出区，中间作为 DC-DC 模块区，下边作为 RK 输出、小信号和测试区。

### 模块安装区

LTC3780 模块差异较大，第一版不要把它画成死封装。建议做一个丝印框和可兼容固定孔：

```text
模块丝印框：82mm x 52mm
丝印框左下角约：(7, 17)
丝印框右上角约：(89, 69)
模块固定孔：先做 4 个 M3 长圆孔/大孔预留，最终按实物调整
模块输入/输出：用短线从模块端子接到 J3/J4
```

如果最终购买的 LTC3780 模块确认为 `78mm x 46mm` 左右，可以让模块长边沿 X 方向摆放，模块上方离高电流母线至少留 `4mm-6mm` 间距，下方保留接线和调电位器操作空间。

### 关键连接与铜皮策略

| 路径 | 建议实现 |
|---|---|
| J1 -> F1 -> SW1 -> J2 | 顶/底层大面积铜皮并联，尽量直线，允许开窗补锡 |
| BAT_SW_12V -> F2 -> J3 | 宽铜皮，不要细线；靠近 DC-DC 输入 |
| J4 -> J5 | 宽铜皮，输出滤波电容靠近 J5 |
| 所有 GND | 大面积 GND 铺铜，输入、电机、RK 输出回流路径保持宽且短 |
| BATT_SENSE | 从 BATT+ 通过 R1/R2 分压后走细线，远离 J1/J2 大电流铜皮 |
| LED1 | 接 BAT_SW_12V，用限流电阻，不参与主电流路径 |

如果嘉立创免费 1oz 板承载发热偏高，优先在 J1-J2 主电流路径做以下增强：

- 顶层和底层同时铺铜；
- 使用多排过孔把上下层铜皮并联；
- 在主电流铜皮上开阻焊窗，手工补锡；
- 必要时沿主电流路径焊一段裸铜线或铜条；
- 第二版再考虑 2oz 铜厚。

### 走线与铺铜

第一版 1oz 免费板不适合用细线跑大电流。建议：

- 电池输入到电机输出使用大面积铺铜，不使用细线；
- 顶层和底层都铺 `BAT_SW_12V` / `GND` 铜皮；
- 使用过孔阵列连接上下层铜皮；
- 大电流焊盘之间可开窗露铜，必要时上锡或焊铜线补强；
- RK 12V/5A 支路至少使用宽铜皮，避免长细线；
- 分压采样线远离电机支路，必要时用 GND 包围；
- DC-DC 输入输出回路尽量短。

### 丝印

必须清楚标注：

```text
BATT IN 3S 12V
MOTOR OUT
RK 12V OUT
DC5525 TO RK3588
GND
BAT+
SW ON/OFF
FUSE RATING
DO NOT CHARGE HERE
```

充电口提醒：

```text
Battery charge port DC5521 stays on battery pack.
This PCB is discharge/power-distribution only.
```

## 上电测试流程

### 1. 空板检查

- 检查 `BATT+` 与 `GND` 是否短路；
- 检查 `RK_12V` 与 `GND` 是否短路；
- 检查 T 插正负极丝印；
- 检查保险丝和开关方向；
- 检查安装孔不会碰到铜皮或外壳。

### 2. 不接 RK / 不接电机

- 接实验电源或电池；
- 串联限流或先用小保险；
- 打开开关；
- 测量 `BAT_SW_12V`；
- 调 LTC3780 输出到 `12.0V`；
- 测 `RK_12V` 空载电压；
- 测 `BATT_SENSE` 是否符合分压预期。

### 3. 接假负载

- 在 RK 输出接电子负载或功率电阻；
- 先测 `12V/1A`；
- 再逐步到 `12V/3A`；
- 短时验证 `12V/5A`；
- 观察 DC-DC 发热、电压跌落和保险丝温升。

### 4. 接 RK3588

- 先不接电机驱动板；
- RK3588 单独由电源板供电；
- 验证开机稳定、视频编码负载稳定；
- 观察 RK 输入电压和 DC-DC 温度。

### 5. 接电机驱动板

- RK3588、ESP32、电机驱动板共地；
- 先低速空载测试；
- 再低速落地测试；
- 观察电机启动时 RK 是否重启；
- 观察电池电压下陷；
- 根据实测调整保险丝规格和线径。

## 待确认项

- 实际购买的 LTC3780 模块尺寸、孔距、端子位置；
- 实际购买模块是否有足够散热片、保险丝和欠压保护调节；
- T 插是否坚持板载封装，还是使用线束焊盘；
- 总开关采用板载大电流开关还是外置开关接口；
- RK 输出使用 5.08mm 端子、XT30，还是直接焊 DC5525 线；
- 是否第一版就加入 5V DC-DC；
- 电机驱动板最大实际电流；
- 底盘内部安装孔位和线缆方向。

## 下单前人工复核清单

- 电池 T 插正负极与 J1 丝印一致；
- 电机驱动输出 T 插正负极与 J2 丝印一致；
- RK3588 的 DC5525 线为中心正极、外壳负极；
- F1/F2 保险丝可拆换，且额定值已在丝印或装配图标注；
- SW1 若为外置开关，开关额定 DC 电流满足主回路电流；
- J1 到 J2 主电流路径没有被细线或热焊盘瓶颈卡住；
- 安装孔周围留出机械避让，螺丝/铜柱不会碰到电源铜皮；
- LTC3780 模块调压电位器装配后还能被螺丝刀触达；
- LTC3780 输出在接 RK3588 前已离线调到 `12.0V`；
- 板上明确丝印 `DO NOT CHARGE HERE`，避免误把电池充电器接到分配板。

## 当前建议

第一版按最稳妥方案推进：

```text
100mm x 100mm 内
2 层 1oz 免费板
T 插线束焊盘
外置大电流总开关接口
总保险 + RK 支路保险
LTC3780 模块载板
RK 12V 输出端子 -> DC5525 线
电池电压分压采样
4 x M3 安装孔
```

先验证整车供电、接线和安装，再根据实测决定第二版是否上 2oz 铜厚、板载开关、固定 DC-DC 封装或集成 5V 支路。
