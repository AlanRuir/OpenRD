# 09 电源分配板嘉立创 EDA 绘制手册

本文档是 `docs/08_power_distribution_board.md` 的落地执行版，用于在嘉立创 EDA 网页版里绘制 OpenRD 车载电源分配板 v0.1。

`08` 负责设计方案和约束，本文档负责具体怎么画原理图、怎么建封装、怎么摆 PCB、怎么检查。

## 版本目标

第一版做一块电源分配/模块载板，不自研 buck-boost 电源。

```text
3S 12V Battery
  -> T plug input
  -> total fuse
  -> external main switch
  -> 12V bus
     -> T plug output to motor driver and ESP32
     -> fuse -> LTC3780 buck-boost module -> 12V DC5525 output to RK3588
     -> battery voltage divider and test points
```

约束：

- PCB 不超过 `100mm x 100mm`；
- 推荐板框 `95mm x 95mm`；
- 2 层板，第一版按 `1oz` 铜厚设计；
- 4 个 M3 安装孔；
- T 插优先用线束焊盘，不使用固定板载 T 插封装；
- LTC3780 模块先作为模块安装区处理，不把模块封装写死；
- RK3588 输出使用 `DC5525` 公头线，中心正极、外壳负极。

## EDA 工程设置

创建工程：

```text
OpenRD Power Distribution Board v0.1
```

推荐设置：

| 项目 | 建议 |
|---|---|
| 单位 | mm |
| 原理图栅格 | 2.54mm |
| PCB 粗摆栅格 | 1mm |
| PCB 精调栅格 | 0.25mm 或 0.5mm |
| 板层 | 2 层 |
| 板厚 | 1.6mm |
| 铜厚 | 1oz |
| 板框 | 95mm x 95mm |
| 原点 | 左下角 |

## 交付文件格式

当前仓库中的 `08/09` 是设计文档，不是原理图文件。

如果在嘉立创 EDA 网页版中完成绘制，标准交付应包含：

```text
EasyEDA / 嘉立创 EDA 工程源文件
Gerber 制造文件
BOM 元器件清单
Pick and Place / 坐标文件，可选
PDF 原理图，可选
PDF/PNG 装配图，可选
```

其中：

- 原理图和 PCB 的可编辑源文件应优先保留为嘉立创 EDA 工程源文件；
- `Gerber` 只用于打板制造，不能替代可编辑原理图；
- `BOM` 只描述元件，不能替代原理图；
- `PDF 原理图` 适合审阅，但不是可编辑工程；
- 若后续在本仓库保存 EDA 文件，建议放到 `hardware/openrd_pdb_v0_1/`。

当前已生成第一版 EasyEDA Standard 源文件：

```text
hardware/openrd_pdb_v0_1/easyeda_std/openrd_pdb_v0_1_schematic.json
hardware/openrd_pdb_v0_1/easyeda_std/openrd_pdb_v0_1_pcb.json
hardware/openrd_pdb_v0_1/easyeda_std/openrd_pdb_v0_1_bom.csv
hardware/openrd_pdb_v0_1/easyeda_std/openrd_pdb_v0_1_easyeda_std.zip
```

导入嘉立创 EDA 专业版时优先使用 `openrd_pdb_v0_1_easyeda_std.zip`。如果 ZIP 导入失败，再分别导入 schematic/PCB JSON，并在网页编辑器中保存为原生工程。

设计规则建议：

| 项目 | 建议值 | 说明 |
|---|---:|---|
| 最小线宽 | 0.25mm | 小信号用 |
| 最小间距 | 0.25mm | 普通制造能力足够 |
| 小信号过孔 | 0.6/0.3mm | 外径/孔径 |
| 大电流过孔 | 1.2/0.6mm 或更大 | 用阵列并联 |
| 安装孔禁布铜 | 直径至少 7mm | M3 螺丝避让 |
| 主电流铜皮间距 | >= 1mm | 降低误焊和毛刺风险 |

## 原理图页面规划

建议只用一个原理图页，分成 4 个区域：

```text
左上：BATT_IN / F1 / SW1 / MOTOR_OUT
右上：RK branch fuse / DCDC_IN / DCDC_OUT / RK_OUT
左下：battery sense / ADC header
右下：LED / test points / mounting holes
```

不要把 LTC3780 当成芯片画。第一版只画：

```text
J3 DCDC_IN  -> 外接 LTC3780 IN
J4 DCDC_OUT <- 外接 LTC3780 OUT
```

这样不同供应商模块孔距或端子方向不同，也不会破坏电气设计。

## 自建封装建议

### T 插线束焊盘

用于 `J1` 和 `J2`。

建议封装：

```text
名称：PWR_WIRE_PAD_2P_10MM
焊盘数量：2
孔径：3.0mm-3.2mm
焊盘外径：6.5mm-7.5mm
中心间距：10mm
焊盘形状：圆形或椭圆
阻焊：默认开窗
丝印：明确 + / -
```

每个 T 插线束焊盘旁边加 2 个扎带孔：

```text
孔径：3.0mm-3.2mm
孔中心距：8mm-12mm
用途：线束应力释放
```

说明：T 插本体不一定要焊到 PCB 上。第一版更推荐 T 插线束一端接电池/电机驱动，另一端焊到 PCB 大焊盘，再用扎带固定线束。

### 5.08mm 端子

用于 `SW1`、`J3`、`J4`、`J5`。

```text
封装：TerminalBlock_2P_5.08mm
额定电流：优先选 10A 或更高
走线侧：留足螺丝刀操作空间
```

如果买不到额定足够的端子，`J3/J4/J5` 也可以改成大焊盘直焊线。

### 保险丝座

`F1` 优先使用汽车片式保险丝座，原因是好买、可更换、能承受较大电流。

第一版默认：

```text
F1: 10A
F2: 5A-7.5A
```

实际值要在实车电流测试后调整。

### LTC3780 模块安装区

v0.1 先固定一个通用模块尺寸用于绘板。这个尺寸用于首版草图，后续按实际购买模块复核。

```text
模块本体：78mm x 46mm
高度避让：15mm
丝印/禁布框：82mm x 52mm
安装孔：4 x M3
安装孔孔径：3.2mm
安装孔孔距：70mm x 38mm
孔中心距模块本体边缘：4mm
模块长边沿 X 方向摆放
模块四周至少留 2mm 机械余量
模块上方远离 J1-J2 主电流铜皮
```

固定方式：

- 在 PCB 上画模块丝印框和禁布框；
- v0.1 先按 `70mm x 38mm` 孔距做 4 个 M3 通孔；
- 如果实际 LTC3780 模块孔距不同，优先只移动模块孔位；
- 模块输入/输出端子用短粗线接到 `J3/J4`，不要强行把模块端子焊死到 PCB。

以 U1 中心 `(48, 43)` 为默认摆放点：

```text
U1 body bbox: x=9..87, y=20..66
U1 keepout bbox: x=7..89, y=17..69
U1H1: (13, 24)
U1H2: (83, 24)
U1H3: (13, 62)
U1H4: (83, 62)
```

## PCB 摆放顺序

不要先自动布线。这个板子的关键不是线多，而是电流路径要对。

建议顺序：

1. 画 `95mm x 95mm` 板框；
2. 放 H1-H4 四个 M3 安装孔；
3. 放 J1、F1、SW1、J2，形成上边主电流通道；
4. 放 LTC3780 模块丝印框；
5. 放 F2、J3、J4、J5；
6. 放 C1/C2/C3/C4；
7. 放 J6、J7、LED、TP；
8. 先画主电流铜皮；
9. 再画 RK 支路铜皮；
10. 最后画采样线和 LED 线；
11. 铺 GND 铜；
12. 加过孔阵列；
13. 加丝印警告。

这些坐标是草案，不是制造尺寸。实际画板时优先保证：

- F1、SW1 不挡线束和螺丝；
- LTC3780 散热片不碰到其他器件；
- J5 的 DC5525 线能顺畅走向 RK3588；
- J6/TP 不靠近电机大电流铜皮。

## 铜皮和走线

### 主电流路径

`J1 -> F1 -> SW1 -> J2` 是最重要的路径。

建议：

- 顶层铺 `BAT_SW_12V / MOTOR_12V` 大铜皮；
- 底层铺 GND 大铜皮；
- 如果正极和地都要跨层，使用多排大过孔；
- 主电流焊盘之间尽量不要用细线连接；
- 开窗露铜，手工补锡；
- 必要时焊铜线加强。

### RK 支路

`BAT_SW_12V -> F2 -> J3 -> LTC3780 -> J4 -> J5`。

建议：

- J3/J4/J5 之间用宽铜皮；
- J4 到 J5 尽量短；
- C3/C4 靠近 J5；
- RK 输出丝印必须写 `12V OUT TO RK3588 DC5525`；
- DC5525 线必须标明中心正极。

### 采样和 LED

采样线不是电流线。

建议：

- R1/R2/R3 靠近 J6；
- `BATT_SENSE` 远离 J1/J2 主电流焊盘；
- 采样线周围可以铺 GND；
- LED 放在板边，便于看见；
- LED 串联限流电阻后接 `BAT_SW_12V`。

## 丝印要求

必须有：

```text
OpenRD PDB v0.1
BATT IN 3S 12V
MOTOR OUT
RK 12V OUT
DC5525 CENTER POSITIVE
DO NOT CHARGE HERE
F1 TOTAL FUSE
F2 RK FUSE
SW MAIN SWITCH
GND
BAT+
```

建议在 J1/J2/J5 附近用大字号标 `+` 和 `-`。

## ERC/DRC 检查点

### ERC

- 所有连接器电源脚都有明确网络名；
- `NC_REF` 不误接到 3V3 或 BATT+；
- LED 方向正确；
- R1/R2 分压方向正确；
- J5 正负极和 DC5525 线定义一致。

### DRC

- 主电流铜皮没有被热焊盘缩细；
- 大电流焊盘之间间距足够；
- 安装孔周围没有铜皮；
- 板边到铜皮距离满足制造规则；
- 丝印没有压到焊盘；
- 模块安装孔不会穿过大电流铜皮；
- 过孔阵列没有被阻焊或间距规则报错。

## 出 Gerber 前检查

1. 打印 1:1 PDF；
2. 把实际 T 插线束、保险丝座、开关线、LTC3780 模块、DC5525 线放到纸上比对；
3. 确认线缆方向不会和底盘结构冲突；
4. 确认 M3 安装孔和底盘孔位或支架位置匹配；
5. 确认模块散热片高度不会碰到上盖；
6. 确认 J1/J2/J5 正负极；
7. 确认 `DO NOT CHARGE HERE` 丝印存在；
8. 确认 LTC3780 调压电位器可触达。

## 首板装配建议

首板不要一次焊满所有东西。

推荐顺序：

1. 先焊 J1、F1、SW1、J2；
2. 检查主电源路径导通和短路；
3. 焊 LED 和测试点；
4. 上电确认 `BAT_SW_12V` 和 LED；
5. 焊 F2、J3、J4、J5；
6. 离线调好 LTC3780 输出 `12.0V`；
7. 接入 LTC3780；
8. 空载测 `RK_12V`；
9. 接假负载测 `12V/1A`、`12V/3A`、短时 `12V/5A`；
10. 最后接 RK3588 和电机驱动板。

## 当前不能定死的项目

以下项目需要实物或购买链接确认后再定：

- LTC3780 模块真实长宽高；
- LTC3780 模块安装孔孔径和孔距；
- LTC3780 输入/输出端子方向；
- F1/F2 保险丝座封装；
- SW1 外置开关线束接口；
- J1/J2 T 插线束实际线径；
- 底盘内部安装孔位置和出线方向。

在这些项目未确认前，可以先完成原理图和大致 PCB 摆放，但不要下单。
